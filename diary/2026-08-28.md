## Bugs I Found & Fixed
- **BOM Encoding in TOML**: UTF-8 BOM in pyproject.toml caused initial parser failures in pytest.
  - *Fix*: Re-encoded pyproject.toml as standard UTF-8 without BOM.
- **Circular Import in Backtest**: Importing ForecastEngine in backtest caused cyclic module dependency during engine init.
  - *Fix*: Refactored type annotations using TYPE_CHECKING and localized constructor imports.
- **Offset-Aware Timezone Comparison**: Mixed naive and UTC datetimes in lifecycle sweep caused TypeError.
  - *Fix*: Introduced _ensure_utc helper ensuring all timestamps are consistently UTC offset-aware.
- **Missing ScenarioRepository**: ScenarioEngine imported ScenarioRepository before it was defined in repositories.py.
  - *Fix*: Implemented ScenarioRepository with async create and get methods mapped to ScenarioModel.
