- **Redundant SQLite Index**: Duplicate index definition on `status` column collided with table arguments during in-memory SQLite schema creation.

- **ModelPromotion Gate Attribute**: Test attempted to read `promoted.is_active` on Pydantic `ModelInfo` which was absent from schema.
