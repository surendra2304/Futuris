## Bugs I Found & Fixed
- **AutoETS State Space Explosion**: AutoETS with 288-step seasonality froze for 90+ seconds; capped seasonal steps to 24, restoring execution in 0.46s.
- **FastAPI Header Type Binding**: Programmatic calls passed Header object into SQL queries causing parameter binding errors; added type guard.
- **Datetime Method Shadowing in Leakage Check**: Checking `.timestamp` attribute on datetime instances returned a callable method rather than value; fixed check order.
- **Missing ECE Metric Key in Pipeline**: Calibration metrics returned `ece_score` but caller expected `ece`; provided both keys.
- **ResolutionMethod Enum Name Mismatch**: Router referenced `ResolutionMethod.AUTOMATED_TELEMETRY` which mapped to `AUTOMATIC`; unified enum aliases.

## Key Decisions & Architecture
- Enforced invariant: prediction is not authorization. Futuris provides calibrated forecasts and scenarios, but never executes mitigations or website changes.
- Embedded uncertainty distributions (p10, p50, p90) and empirical calibration metrics (ECE, Brier score) directly in all task responses.
- Enforced SHA-256 immutable audit logging on all mutation operations via AuditLogger.
