## Security ledger (Phase 10)
Verified live + by reading. Severity: C/H/M/L.

1. **[M] Default/placeholder credentials shipped in `.env.example`**: `FUTURIS_API_KEY=futuris_api`, `FUTURIS_FRIDAY_API_KEY=friday_secret_key_default`, `INFERENCE_API_KEY=inference_api`, `MEMORA_API_KEY=memora_api`, `STRATEX_API_KEY=stratex_api`, `INTELX_API_KEY=intelx_api`. If copied to `.env` verbatim in dev: FRIDAY guard would 503 (<32 chars, fail-closed — good), but master key `futuris_api` WOULD authenticate as admin (13 chars, no length check on master key in get_current_user). Also `.env.example` sets `API_KEYS_ENABLED=false` while code default is True — copying the example DISABLES auth in dev. Remediation: ship empty values + comments; add master-key length check (≥32) in get_current_user; make API_KEYS_ENABLED non-disableable outside explicit dev.
2. **[M] Hardcoded fallback connector credentials** (silent use when unconfigured): connectors/nexus.py:25 `nexus_default_token`; connectors/forge.py:26 `forge_default_secret_key`; connectors/intelx_context.py:43 `intelx_default_token`; connectors/trading_bot.py:26 `trading_bot_default_key` and :38-39 `read_key_default_secret_123`. These are sent as Bearer/X-API-Key to peer services. If any peer accepts them, that's a backdoor; they also leak the *pattern* of guessable credentials. Remediation: require explicit key, fail/warn loudly.
3. **[M] Anonymous compute-heavy endpoints (DoS surface)**: GET /v1/market/forecast (AllowAnonymousRead) runs the full market pipeline incl. outbound IntelX/Stratex/Inference calls and a DB write per call; GET /v1/predictions/matrix backfills missing targets within a 15s budget (multiple pipeline fits); GET /v1/ecosystem/peers probes 8 external peers per call. No rate limiting on any of these (rate limit exists only on FRIDAY routes, in-memory). Remediation: require viewer on market GET; cache matrix/peers; rate-limit anonymous reads.
4. **[M] render.yaml + SQLite on ephemeral disk**: Render free plan, `DATABASE_URL=sqlite+aiosqlite:////app/data/futuris.db` — free-plan disks are ephemeral; every restart loses all forecasts/outcomes/audit. Architecture assumes durable disk. Remediation: Postgres on Render, or document the limitation.
5. **[L] Master-key comparison not constant-time**: infra/auth.py:88 `clean_key == settings.FUTURIS_API_KEY` (FRIDAY guard and inbound webhook use hmac.compare_digest — inconsistent). Timing side channel over network is largely impractical, but fix for consistency: compare_digest.
6. **[L] Unhandled-exception handler leaks internals**: api/errors.py unhandled handler returns `"details": str(exc)[:300]` — DB paths, library internals to clients. Remediation: generic detail, log the specifics.
7. **[L] In-memory-only state**: webhook subscriptions, rate-limit buckets, idempotency store (upgrade/), LLM cache, circuit breakers, seed guard — all per-process; multi-worker/replica deployments lose or diverge. Documented in some docstrings ("Production should use Redis").
8. **[L] Committed binary SQLite artifacts**: `futuris_demo.db` (163KB) + `futuris_demo.db-journal` (95KB) tracked in git; verified all 11 tables exist with ZERO rows. `.gitignore` lacks `*.db` (`.dockerignore` has it). Hygiene/foot-gun (a stale journal next to a db). Remove from git.
9. **[L] `docker-compose.yml` hardcoded credentials**: postgres/postgres for local dev (acceptable for local, but copy-paste risk); also compose api service does not set FUTURIS_API_KEY → API_KEYS_ENABLED default True + no master key → all protected routes anonymous-blocked; fine but confusing.
10. **[L] `/v1/task/execute` unauthenticated** (both /v1 and /api/v1): by design fail-closed (403 forbidden actions / 501 otherwise), but it is an unauthenticated POST surface; the forbidden-action denylist is blocklist-based (new action names fall through to 400/501, not execution — safe, but worth noting the design relies on the denylist for the 403 semantics).
11. **[L] Audit coverage not universal**: SECURITY.md §4 says "Every mutating API action logs". Verified audit actions: create_forecast, invalidate_forecast, resolve_forecast_manual, generate_forecast (friday), evaluate_scenario (friday), cancel_forecast (friday), resolve_forecast ×2 (friday), create_market_forecast, request_universe_prediction. NOT audited: scenario runs via /v1/forecasts/{id}/scenarios, webhook subscribe/delete, ecosystem seed trigger (seed logs via logger only), self/peers reset, self/heal. Partially true claim.
12. **[L] MEMORA_API_KEY aliases include FUTURIS_API_KEY** (config.py:99-103): the master key doubles as the Memora credential — blast-radius coupling. Similarly FRIDAY guard falls back to master key, and inbound webhook auth falls back through FRIDAY key → master key. One leaked master key = everything.
13. **[L] `getattr(settings, "AUTH_DISABLED", False)`** (auth.py:74) is dead: not a declared Settings field, extra="ignore" → always False. Misleading — looks like an auth bypass switch.
14. **[L] API keys stored as unsalted SHA-256** (auth.py hash_api_key): fine for high-entropy keys (generate_api_key = 24-byte hex), but the scheme offers no protection if a low-entropy key is ever imported; upgrade/auth.py CredentialHasher (PBKDF2 310k, ≥100k enforced, min secret 20 chars) exists but is not wired into ApiKeyModel.
15. **[L] Universe risk scale mismatch** (core/universe_domains.py:346-368): for unit="%" targets, metric = probability if present else prediction; thresholds are 0–1 scale (e.g. 0.30/0.60) but caller-supplied point estimates are 0–100 scale → prediction 42.0 vs critical 0.60 → CRITICAL. Verified live: sentinel target with point_estimate=42.0 → risk_level=CRITICAL and interpretation "0.0% probability of elevated security anomaly activity" (template formats probability None → 0.0). Two cosmetic/logic bugs in the same path.
16. **[L] Quality gate manufactures inputs for non-envelope objects** (upgrade/quality.py:62-77): defaults prediction/lower/upper=0.0, confidence 0.85/0.65/0.45 → `require()` can pass on fabricated numbers if a caller passes a bare object. API path passes a real ForecastEnvelope, so latent only.
17. **[L] `LifecycleManager.resolve_manual(forecast_id: uuid4, ...)`** (core/lifecycle.py:100): annotation is the `uuid4` function, not `UUID` type — cosmetic type bug (runtime unaffected).
18. **[INFO] PII posture**: evidence snapshots strip denylist columns before freezing; audit log stores SHA-256 payload hashes (not payloads); IntelX finding_summary (≤8000 chars) stored in intelx_notices; API keys hashed; no user accounts/PII in forecasts. UI stores API key in localStorage. No PII in logs observed (structlog events use IDs/labels).
19. **[INFO] Good security properties verified**: fail-closed FRIDAY auth (503 unconfigured/short key, constant-time); PBKDF2 credential hasher; production import-time secret guard (unconditional, both spellings, placeholder denylist); webhook SSRF guard incl. DNS-resolution check; HMAC-signed webhooks with retry; append-only event/audit repositories (update/delete raise ReadOnlyAuditViolationError); evidence immutability (re-write raises); LIVE evidence requires non-empty SHA-256 (is_real_hash rejects EMPTY_SHA256); PII denylist; SQL fully parameterized (SQLAlchemy select/update, no raw SQL concatenation found); prediction_is_not_authorization enforced as Pydantic invariant + 403 guards on /v1/task/execute and /v1/friday/delegate + ActionSuggestion validator; demo seeding forbidden in production (startup_policy + SourcePolicy); CI pins Python 3.11.
20. **[INFO] Dependency audit**: pip-audit clean on requirements.txt (2026-10-07). Not checked: npm audit for UI (node_modules not installed in sandbox; package-lock.json present), uv.lock consistency.
21. **[L] No security headers** (no HSTS/CSP/X-Content-Type-Options middleware) and no CORS middleware (FastAPI default = same-origin only — safe default); /docs and /openapi.json are publicly exposed in production (render.yaml does not disable them) — information disclosure of the full API surface; consider disabling in prod.
22. **[M] Inbound IntelX webhook writes + triggers reforecast** with only a shared secret; finding_summary up to 8000 chars stored and later injected into forecast drivers/rationale (up to 45 chars label / 2000 headline to Memora) — external content flows into served forecasts; mitigated by labeling (synthetic/LOW confidence) and the ±context-only driver attachment (does not move the statistical estimate). ContextFirewall exists in upgrade/ for LLM prompts but is not wired into the IntelX path.
